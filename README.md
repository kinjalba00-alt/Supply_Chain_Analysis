#Supply Chain & Delivery Analytics Portfolio Project

This project represents a complete, industry standard, end-to-end data analytics workflow, designed to mirror the real responsibilities of professional analysts in modern business environments. The project encompasses all critical stages of data analysis, from data preparation and modeling to insight generation, visualization, and reporting.

This project is perfect for:
- 📊 Data Analyst aspirants who want to build a strong Portfolio Project for interviews and LinkedIn
- 📚 Anyone learning Python and Power BI
- 💼 Professionals preparing for interviews in Data Analytics, Data Science or Supply Chain Analytics roles

📌 Project Overview

The goal of this project is to simulate a corporate-grade end-to-end data analytics workflow, demonstrating the ability to translate raw quick-commerce delivery data into strategic business intelligence by:

✅ Data Preparation, Modeling & Exploratory Data Analysis (Python):** Clean and transform the raw delivery dataset for analysis.

✅ Data Analysis: Identify delivery bottlenecks, analyze customer ratings vs delivery partner performance, and uncover purchase and discount drivers across companies like Jio Mart, Zepto, Blinkit, Big Basket, Amazon Now, Swiggy Instamart, Flipkart Minutes, and Dunzo.

✅ Visualization & Insights (Power BI):** Build an interactive dashboard that highlights key patterns and trends, enabling stakeholders to make data-driven decisions.

✅ Report and Presentation: Write a clear project report summarizing key findings and business recommendations.

🛠️ How to Use This Project

1. Clone the repository
```bash
git clone https://github.com/kinjalba00-alt/Supply_Chain_Analysis.git
cd Supply_Chain_Analysis
```

2. Open `supply_chain_analysis.ipynb` notebook

This file contains:
- Data Import
- Data exploration
- Data cleaning & preprocessing
3. Review the raw dataset
- Open `quick_commerce_data_raw.csv` to explore the source data
- Fields include: Order details, Company, City, Customer Age, Order Value, Delivery Time, Distance, Product Category, Payment Method, Ratings, and Discounts
4. Explore the Power BI Dashboard
- Open `Suppy_Chain_Analysis_Dashboard.pbix` in Power BI Desktop
- Interact with the dashboard using slicers (Company, City, Payment Method, Product Category, Discount)
5. Review the Project Report
- Open `Supply_Chain_Analysis.pdf` for the full written analysis and business recommendations

 📊 Key Metrics Analyzed
- Total Orders & Average Order Value
- Average Delivery Time by City & Company
- Customer Rating vs Delivery Partner Rating
- Discount Impact on Orders and Revenue
- Revenue Distribution by Company & Product Category

 📈 Dashboard Highlights
- Orders Distribution by Product Category (Donut Chart)
- Total Revenue by Company (Column Chart)
- Average Delivery Time by City (Line Chart)
- Category-wise Orders: Discount vs No Discount (Bar Chart)
- Customer vs Delivery Partner Rating Comparison (Bar Chart)
